Project History

AI.py started as a small educational Python CLI project and grew into a massive codebase with over 5 million lines of code. What began with basic text processing and math utilities expanded into a comprehensive assistant with thousands of data tables, games, ASCII art, network tools, cryptography, and the HBPE educational programming language.

The project evolved through 19 version releases from v3.0.2 to v6.0.0, adding thousands of functions, dozens of data modules, and a full static website hosted on Vercel.

Architecture

  • AI.py — Main CLI entry point (500K+ lines, 8,577 commands)
  • data_bulk*.py — 30 procedurally generated data modules (5,300+ functions)
  • data*.py — 21 curated real-world data tables
  • gen_*.py — Code generators for utility functions and bulk data
  • hbpe*.py — HubBasePE educational programming language engine
  • deploy_temp/ — Vercel-deployed static website (16 HTML pages)

Technology Stack

  • Language: Python 3.14+
  • Website: Vanilla HTML/CSS, Vercel hosting
  • Version Control: Git, GitHub
  • CI/CD: Vercel auto-deploy from master branch
  • Analytics: Vercel Analytics & Speed Insights
