Overview

AiScript is a Python-inspired scripting language implemented as a single aiscript.py file — no external dependencies, no compiler, no pip install. It features a full lexer, parser, AST, and tree-walking evaluator, plus an interactive REPL and CLI script runner.

Designed for quick scripting, education, and embedding into larger Python applications via import aiscript. AiScript runs anywhere Python 3 does.

Features

  • Python-like syntax — familiar def, class, if/elif/else, while, for, import
  • Dynamic typing — variables hold any type; no declarations needed
  • First-class functions — functions are values, support nested scope and closures
  • Classes & objects — full OOP with dot access, method calls, self parameter
  • Lists & dicts — built-in collection types with in/del operators
  • String methods — dot-accessible .upper(), .lower(), .strip(), .replace(), .split(), .join() and more
  • 26+ built-in functions — print, input, len, int, str, range, type, exit, open/read/write, split/join, reverse, sort, min/max/sum, abs, randint, sleep, and more
  • Built-in modules — json (load/dumps), time (sleep/strftime), sys (argv/exit)
  • REPL & CLI — run interactively or pass a file: python aiscript.py script.ais
  • Embeddable — import aiscript; aiscript.run_script("print 1+1")

Hello World

Functions & Recursion

def factorial(n) {
    if n <= 1 {
        return 1
    }
    return n * factorial(n - 1)
}

print factorial(5)  # 120

Classes

class Animal {
    def init(self, name) {
        self.name = name
    }
    def speak(self) {
        return self.name + " makes a sound"
    }
}

class Dog : Animal {
    def speak(self) {
        return self.name + " says woof!"
    }
}

d = Dog("Rex")
print d.speak()

Lists & Loops

fruits = ["apple", "banana", "cherry"]
for fruit in fruits {
    print fruit
}

nums = range(1, 6)
squared = []
for n in nums {
    squared.append(n * n)
}
print squared

Kite IDE

Kite v0.2.1 — AiScript Editor & Runner

Kite is an IDLE-inspired code editor for AiScript, built with Python's tkinter. It provides a familiar editing environment with syntax highlighting, line numbers, and integrated script execution.

  • Syntax highlighting — keywords, strings, numbers, comments, builtins in distinct colors
  • Line numbers — left-hand gutter with line count
  • Run (F5) — execute the current script in the built-in output console
  • Run External (Ctrl+F5) — execute in a separate terminal window
  • File menu — New, Open, Save, Save As
  • Dark theme — GitHub-dark color scheme
  • Undo support — full undo/redo history
  • Status bar — cursor position, file name, version info

Quick Start

Run a script

python aiscript.py myscript.ais

Interactive REPL

python aiscript.py

From Python

import aiscript
aiscript.run_script('print "hello from AiScript"')
aiscript.run_file('script.ais')

Using Kite IDE

Double-click kite.cmd or an .ais file to open in Kite. Press F5 to run.
