AI.py FAQ

Frequently asked questions about AI.py v5.2.0

Q: What is AI.py?

A massive Python CLI assistant with 4,200+ data functions, 4.5M+ lines of code, and 26 bulk data modules. It includes text processing, math, games, ASCII art, network tools, cryptography, and more.

Q: How do I install AI.py?

Download the Visual Installer (AIInstaller.exe) or run python AI.py directly after downloading all the Python files. Requires Python 3.14+.

Q: How many commands does AI.py have?

3,911 CLI commands across 15 categories. You can explore them with help or help2.

Q: What are data_bulk files?

They are procedurally generated data tables covering topics from world geography to robotics to finance. There are 26 bulk modules with 4,200+ functions, each returning 500-1,500 entries.

Q: How do I update AI.py?

Use the CLI Updater (AIUpdater.exe) or run python updater.py. You can also download the latest files from the Downloads page.

Q: What is HBPE?

HubBasePE is a custom educational programming language included in AI.py. It has two supported versions (v0.0.1.2.01 and v0.0.2.0.00b1) and 25 built-in programs.

Q: How do the roles work?

Four access levels: User, VIP, Mod, and Admin. Each has a distinct badge color and command set. See the User Guide for details.

Q: Can I export data tables?

Yes! Use export_csv, export_json, or export_markdown to export any data table to a file.

Q: How do I search for a command?

Use find <keyword> to search all command names and descriptions. Or use whatis <command> for details on a specific command.

Q: Where can I report bugs or request features?

Open an issue on GitHub at Voice659/AI-repo.
