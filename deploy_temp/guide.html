AI.py User Guide

How to install, run, and use AI.py v5.3.0 — your massive Python CLI assistant

Getting Started

Installation

  1. Python 3.14+ required. Download from python.org.
  2. Create a virtual environment: python -m venv .venv
  3. Activate it: .venv\Scripts\activate (Windows) or source .venv/bin/activate (Linux/Mac)
  4. Download AI.py and all data_bulk*.py files from the Downloads page.
  5. Optional: Use the Visual Installer for one-click setup.

Running AI.py

Simply run the main script:

python AI.py

You will be greeted with an interactive prompt. Type help to see available commands, or help2 for categorized help.

Command System

Basic Usage

AI.py uses a command-line interface. Type a command and press Enter:

> word_count The quick brown fox jumps over the lazy dog
Words: 9, Characters: 44, Sentences: 1

Most commands accept arguments directly or via prompts. Many support flags for additional options.

Categories

Commands are organized into 14 categories:

  • Text — word_count, reverse_string, caesar_cipher, morse code, base64
  • Math — prime_factors, fibonacci, factorial, matrix operations
  • Convert — unit conversions: length, weight, temperature, currency
  • Stats — mean, median, mode, standard deviation, linear regression
  • Games — guess_number, hangman, trivia, tic-tac-toe, 8-ball
  • Drawing — ASCII art: diamond, tree, heart, dragon, spaceship, DNA
  • Network — ip_info, web_fetch, ping, dns_lookup, port_scan
  • Crypto — SHA hashes, AES encrypt/decrypt, password generator
  • DateTime — timer, stopwatch, timezone convert, date math
  • Admin — sys_info, file operations, process list, debug console
  • Learning — quiz, flashcards, data query, random lessons
  • Utilities — calculator, notes, todo, reminders, color picker
  • Data — export CSV/JSON/Markdown, data summary, compare tables
  • HBPE — run HBPE programs, development console, dual-version support

Data System

Data Tables

AI.py includes 4,600+ data tables across 28 bulk modules and 7 curated modules. Each table contains 500-1,500 entries with structured data.

Curated tables (21): hand-verified real-world data — elements, planets, cities, countries, mountains, rivers, lakes, languages, inventions, dinosaurs, oceans, volcanoes, earthquakes, hurricanes, constellations, galaxies, gemstones, minerals, ocean currents, geological formations, soil types.

Bulk tables (4,600+): procedurally generated data across topics like world statistics, food & nutrition, music & arts, animals, space, geography, history, science, sports, technology, business, environment, energy, finance, robotics, medicine, transportation, education — and more.

Using Data

  • data_query <keyword> — search across all data tables
  • quiz_mode <table> — interactive quiz on any table
  • flashcard_study <table> — study with spaced repetition
  • export_csv <table> — export table to CSV file
  • data_random_row <table> — get a random entry
  • data_summary <table> — statistics about a table

Role System

AI.py has four access roles, each with a distinct command set and badge color:

  • Admin — Full access: system commands, user management, all features
  • Mod — Elevated access: moderation tools, debug console
  • VIP — Premium access: exclusive commands, priority support
  • User — Standard access: all core features, games, data query

Use role_info to see your current role. Admins can change roles with set_role.

HBPE Programming

AI.py includes the HubBasePE programming environment — a custom educational language with dual-version support (v0.0.1.2.01 and v0.0.2.0.00b1).

  • hbpe_start — launch the HBPE environment
  • hbpe_run 1-20 — run a built-in program
  • hbpe_run P1-P5 — run a program from the Programs directory
  • hbpe_dev — open the interactive development console
  • hbpe_compat — toggle between HBPE versions

Debug Console

The debug console (debug_console) provides an enhanced REPL environment:

  • Python eval() and exec() support
  • HBPE program execution
  • Command routing and intercept
  • Stop/reset controls

Configuration

Color Theme

Use color_picker to customize the interface colors. Settings persist across sessions.

Reminders & Notes

set_reminder for timed alerts. notes_manager and todo_list for persistent task tracking. All data stored as JSON in the working directory.

Installer Config

The visual installer saves its configuration to installer_config.json for repeat use.

Tips & Tricks

  • Use Tab for command autocomplete
  • help shows all commands; help2 shows them by category
  • whatis <command> for a quick description of any command
  • find <keyword> to search for commands by keyword
  • Prefix commands with ! to repeat last command
  • Use clear to clear the screen
  • Check sys_info for system diagnostics
  • Save your favorite commands with notes
  • Run calc for a full calculator with history
  • Use random_lesson to discover new data daily
