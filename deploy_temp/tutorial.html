AI.py Tutorials

Step-by-step tutorials for AI.py v5.4.0 — 5.7M+ lines, 5,000+ data functions

Getting Started

1. Your First Session

  1. Run python AI.py to start the CLI
  2. Type help to see all available commands
  3. Try word_count to count words in a sentence
  4. Use help2 to see commands organized by category

2. Exploring Data

  1. Use data_query elements to search the elements table
  2. Try random_lesson for a random fact
  3. Use quiz_mode chemistry_element to test your knowledge
  4. Export with export_csv chemistry_element

3. Games & Fun

  1. Type guess_number to play the number guessing game
  2. Try hangman for a classic word game
  3. Use draw_diamond for ASCII art
  4. Ask eight_ball a question

4. Utilities

  1. Use calc for the calculator REPL
  2. Set a timer 60 for a 60-second countdown
  3. Take notes with notes add my note here
  4. Check sys_info for system diagnostics

5. HBPE Programming

  1. Run hbpe_start to launch the HBPE environment
  2. Try hbpe_run 1 to execute the first built-in program
  3. Use hbpe_dev for the interactive development console
  4. Toggle versions with hbpe_compat

6. Advanced Tips

  1. Use Tab for command autocomplete
  2. Prefix commands with ! to repeat the last command
  3. Search commands with find <keyword>
  4. Get help on any command with whatis <command>
  5. Customize colors with color_picker
