# Contributing to AI.py

Thank you for your interest! Here's how to contribute.

## Getting Started

1. **Fork** the repository.
2. **Create a branch** for your change: `git checkout -b your-feature-name`.
3. Make your changes following the existing code style and conventions.
4. **Commit** with a concise message that matches the repo convention.
5. **Push** and open a **Pull Request**.

## Guidelines

- Keep changes focused — one feature/fix per PR.
- Match the surrounding code style (naming, imports, patterns).
- If adding a feature to AiScript, add a test `.ais` file.
- For large changes, open an issue first to discuss.
