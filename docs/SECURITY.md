# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AI.py, AiScript, or any component of this project, please report it through our dedicated discussion:

[https://github.com/Voice659/AI-repo/discussions/2](https://github.com/Voice659/AI-repo/discussions/2)

Please do **not** disclose the vulnerability publicly until it has been addressed.

We will acknowledge receipt within 48 hours and work to resolve the issue promptly.
